# 티처보드 (웹·폰용)

교사용 시간표·수업 도우미. 폰 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 올리는 법 (GitHub Pages)

1. 저장소를 만들고(Public) 이 폴더의 파일 5개를 올립니다.
   - `index.html` `manifest.json` `sw.js` `icon-192.png` `icon-512.png`
2. 저장소 **Settings → Pages → Branch: main / (root) → Save**
3. 1~2분 뒤 주소가 나옵니다 → `https://아이디.github.io/저장소이름/`

## 폰에 설치

폰 크롬에서 그 주소를 열고 → 메뉴(⋮) → **홈 화면에 추가**

## 고칠 때

`index.html` 을 같은 이름으로 다시 올리고, `sw.js` 의 `VER` 숫자를 하나 올립니다
(`tb-v1` → `tb-v2`). 그래야 폰에 남아 있던 옛 화면이 새것으로 바뀝니다.

## 자료 옮기기

PC 티처보드와 폰은 저장 공간이 따로입니다.

- PC: 설정 → 일반 → **💾 백업 저장**
- 그 파일을 폰으로 보내기 (드라이브·메신저 등)
- 폰: 설정 → 일반 → **📂 백업 불러오기**

## 알아둘 것

- 주소가 공개돼도 **자료는 각자 기기 안에만** 저장됩니다. 남이 주소를 열면 빈 화면이 보입니다.
- 폰에서는 화면 녹화, 창 위에 고정, 윈도우 자동 실행 같은 PC 전용 기능이 동작하지 않습니다.
- 급식·날씨·학사일정은 인터넷이 있어야 보입니다. 나머지는 비행기 모드에서도 열립니다.
